# Task: Lab 5 - Архітектура (Component Diagram)

## Мета

Модель архітектури - компоненти, інтерфейси, залежності й межі системи.

## Артефакт

UML Component Diagram у декларативному синтаксисі (PlantUML component / Mermaid) - компоненти (UI, API/Backend, сервіси, Data Access, БД), provided/required-інтерфейси, залежності, чітка межа системи, зовнішні інтеграції (Payment, SMS/Email, OAuth/Identity, External API...). Рендер - компонентна діаграма з цього опису.

## Що зробити

- spec.md: модулі (UI, API, сервіси, Data Access, БД) + зовнішні інтеграції
- Побудувати компонентний модель; згенерувати діаграму
- Аудит: кожен компонент/залежність трасується до попередніх моделей (дані, вимоги, взаємодія, процес); межа системи чітка; provided/required-інтерфейси визначені; топ-3 розбіжності
- DEFENSE.md: як модель інтегрує весь ланцюг моделей

## Ознаки відмінного виконання

- Компоненти, інтерфейси й межі коректні
- Повна узгодженість з моделлю даних, вимогами, взаємодією та процесом
- Аудит присутній
