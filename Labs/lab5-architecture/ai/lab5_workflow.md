Реальний процес: які кроки, в якому порядку, яка модель що робила.

## Ролі моделей

- **SWE-2 Max** — генерація: драфт діаграми, реалізація фіксів, документи, рендери
- **GLM 5.3 Max** — рев'ю: чек-листи, adversarial-прогони, трасування до ланцюга lab1–4

Рознесення по двох моделях — свідоме: генератор систематично не бачить власних дір («правдоподібне дорисування» Email-gateway — саме такий випадок). Рев'юер без авторства дивиться холодніше.

```
task.md -> spec.md -> драфт (SWE-2 Max) -> adversarial-рев'ю (GLM 5.3 Max)
   -> фікс-коміти (spec+model разом) -> рендери -> AUDIT/DEFENSE -> PR
```
