# ADR-002: Mermaid graph для Use Case діаграми

## Статус

Superseded (відмінено після рев'ю — див. примітку внизу)

## Контекст

Для Lab 2 треба use-case-діаграма з акторами, include/extend, узагальненням. Варіанти:

1. **Mermaid graph** - GitHub рендерить нативно, але це не стандартна use-case нотація (нема овалів, лінії замість стрілок)
2. **PlantUML** - стандартна use-case нотація, але не рендериться в GitHub без плагіна
3. **draw.io / Lucidchart** - візуальні редактори, але не текстовий артефакт

## Рішення (історичне)

Обрав Mermaid graph. Використовую `graph LR` з:
- `Actor((Name))` для акторів
- `UC[N]` для use cases
- `-.->|include|` для include
- `-.->|extend|` для extend
- `-.->|generalization|` для узагальнення

## Наслідки

- Плюс: рендериться в GitHub, текстовий артефакт, версіонується
- Мінус: не стандартна use-case нотація (квадрати замість овалів, лінії замість стрілок)
- Компенсую: в spec.md описую зв'язки словами, в AUDIT.md пояснюю нотацію

## Перегляд (після рев'ю викладача)

Рев'ю показало, що мінус «не стандартна нотація» виявився критичним: актори рендерились кругами, UC — прямокутниками, без рамки системи — діаграма читалась як граф, не як use case. Канонічний source замінено на **PlantUML `model/usecase.puml`** (еліпси UC, фігури акторів, `rectangle` boundary, `User --|> Guest`, `..>` include/extend). `usecase.mmd` видалено щоб не тримати два розбіжні джерела однієї моделі. .drawio синхронний семантично.
