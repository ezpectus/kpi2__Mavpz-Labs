# Lab 2 - Use Cases: VideoHub

## Домен

VideoHub - платформа для завантаження та перегляду відео (YouTube-клон).

Реалізація: [github.com/ezpectus/VideoHub](https://github.com/ezpectus/VideoHub)

## Чому цей домен

Продовжуємо з Lab 1 (ER-модель). Домен VideoHub має чітких акторів і сценарії:
- Guest (незареєстрований) - може дивитись і шукати відео
- User (зареєстрований) - може завантажувати, коментувати, лайкати, підписуватись
- Google OAuth Service (зовнішня система) - автентифікація

Це дає 2 типи акторів (людина + зовнішня система) як вимагає умова.

## Примітка щодо проєкту

Структура реального VideoHub старіша і простішa. Use cases тут - доопрацьована версія поверх покращеної ER-моделі з Lab 1 (Google OAuth, непокриті вимоги, трасування M:N).

## Актори

- **Guest** - незареєстрований відвідувач (перегляд, пошук)
- **User** - зареєстрований користувач (upload, comment, like, subscribe)
- **Google OAuth** - зовнішня система автентифікації

## Головні цілі

1. Реєстрація / вхід (вкл. Google OAuth)
2. Завантаження відео
3. Перегляд відео
4. Коментування відео
5. Лайк відео
6. Підписка на канал
7. Пошук відео

## Зв'язок з Lab 1 (ER-модель)

Актори і сценарії спираються на сутності з ER-моделі:
- User -> реєстрація, upload, comment, like, subscribe
- Video -> upload, перегляд
- Comment -> коментування
- Like -> лайк
- Subscription -> підписка
