# ADR-003: Mermaid sequenceDiagram для взаємодії

Для Lab 3 обрав Mermaid sequenceDiagram.

На відміну від use case діаграми (Lab 2) де Mermaid - компроміс (нестандартна нотація), для sequence діаграм Mermaid повністю підтримує UML нотацію: `actor`, `participant`, `->>` для викликів, `-->>` для return, `alt/else/end` для альтернативних гілок, `opt/end` для опціональних, `loop/end` для циклів, вкладені combined fragments. Це все що треба для повноцінної sequence-діаграми.

Розглядав PlantUML (не рендериться в GitHub) і draw.io (не текстовий артефакт, не дифається). Mermaid виграє бо рендериться нативно і підтримує всі потрібні елементи.

Єдиний мінус - обмежене форматування (не можна змінювати кольори, товщину ліній, автоматичне вирівнювання). Для лаби це не критично. Ручну версію для редагування тримаю в model/sequence.drawio.
