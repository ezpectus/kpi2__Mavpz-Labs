# ADR-001: Вибір нотації для ER-моделі

Вибрав Mermaid erDiagram для ER-моделі.

Розглядав три варіанти: Mermaid erDiagram, PlantUML, dbdiagram.io. PlantUML потужніший (більше деталей, підтримка unique-нотації) але треба Java і plantuml.jar, рендер не в GitHub. dbdiagram.io - онлайн інструмент, але не текстовий артефакт, не покладеш в репо.

Mermaid erDiagram рендериться прямо в GitHub - препод відкриває файл і бачить діаграму. Синтаксис простіший. Мінус - не показує unique-обмеження на діаграмі, тому описав їх текстом в spec.md і додав коментар на діаграмі.

Якщо в наступних лабах знадобиться складніша ER-модель - можна перейти на PlantUML.
