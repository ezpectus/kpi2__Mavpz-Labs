# Lab 1 - ER-модель: VideoHub

## Домен

VideoHub - платформа для завантаження та перегляду відео (YouTube-клон).

Реалізація: [github.com/ezpectus/VideoHub](https://github.com/ezpectus/VideoHub)

## Чому цей домен

Обрав VideoHub бо це реальний проєкт який я робив. Домен має різні типи зв'язків:
- 1:N (User -> Video, User -> Comment, Video -> Comment)
- M:N через асоціативну сутність (Like: User <-> Video)
- Self-referencing M:N (Subscription: User <-> User)

Це дозволяє показати всі типи кардинальностей в одній моделі.

## Примітка щодо проєкту

Реальний VideoHub має старішу структуру БД (schema.prisma писався давно і місцями спрощено). Модель у цій лабі - доопрацьована версія: додані unique-обмеження, уточнені кардинальності, Like і Subscription оформлені як повноцінні асоціативні сутності.

## Опис

Користувачі реєструються, завантажують відео, коментують, ставлять лайки і підписуються на канали інших користувачів. Кожне відео має автора (користувача), лайки та коментарі. Підписка - це зв'язок між користувачами (один підписується на канал іншого).

## Сутності

- **User** - користувач (автор відео, коментатор, підписник)
- **Video** - відео, завантажене користувачем
- **Comment** - коментар до відео
- **Like** - лайк користувача на відео (асоціативна сутність User <-> Video)
- **Subscription** - підписка користувача на канал іншого користувача (асоціативна сутність User <-> User)

## Зв'язки

- User -> Video: 1:N (один автор - багато відео)
- User -> Comment: 1:N (один користувач - багато коментарів)
- Video -> Comment: 1:N (одне відео - багато коментарів)
- User <-> Video: M:N через Like (користувач лайкає відео)
- User <-> User: M:N через Subscription (self-referencing, користувач підписується на користувача)
